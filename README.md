# Gobang-game

一个用 C 语言编写的命令行五子棋练习项目。当前版本使用 12 × 12 棋盘，支持两名玩家在同一终端轮流落子。

## 当前内容

- 菜单选择开始游戏或退出；玩家输入“行 列”坐标（均为 1～12）落子。
- 棋盘显示双方棋子，并在坐标超出棋盘或位置已被占用时要求重新输入。
- 包含五子连线和棋盘占满的判定逻辑。
- 代码中保留了尚未启用的电脑落子练习片段；当前入口运行的是双人模式。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `五子棋test.c` | 菜单、游戏循环和程序入口 |
| `五子棋game.c` | 棋盘显示、玩家落子及结果判定 |
| `game.h` | 棋盘尺寸、颜色常量及函数声明 |

## 编译与使用

源码包含 `windows.h`，适合在 Windows 环境下用 MinGW GCC 编译：

```powershell
gcc -std=c11 "五子棋test.c" "五子棋game.c" -o gobang.exe
.\gobang.exe
```

在菜单中输入 `1` 开始双人对局，输入 `0` 退出。游戏中按提示输入行、列坐标，例如 `5 6`。

## 当前限制

这是学习阶段的代码，尚未完成稳定性修整。`game.h` 中的胜负判定声明与实际函数名不一致，编译时会出现函数未声明警告；部分连线判定的循环边界还可能访问棋盘范围之外。修复并验证这些问题之前，不应把它视作稳定版本。
